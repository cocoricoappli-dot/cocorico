COCORICO

Politique de confidentialité

Dernière mise à jour : 25 novembre 2026

Cocorico est une application de contrôle parental. Installée par un parent sur le téléphone de son enfant, elle masque les messages blessants (insultes, harcèlement, menaces, propos racistes, sexistes ou homophobes) dans les applications choisies par le parent.

1. Ce que Cocorico lit

Cocorico utilise le service d'accessibilité d'Android pour lire les textes affichés à l'écran, uniquement dans les applications cochées par le parent (par exemple SMS, Instagram, WhatsApp, TikTok, Snapchat, Discord) et, si le parent le choisit, dans les aperçus de notifications (barre de notifications, écran verrouillé).

Cocorico regarde aussi les écrans des Réglages du téléphone qui permettent de le désactiver ou de le désinstaller, pour les protéger par le code parent.

2. Ce que Cocorico fait de ces textes

Les textes sont comparés, directement sur le téléphone, à une liste de mots et d'expressions. S'ils en contiennent, ils sont recouverts par un rectangle « Message masqué ».

Les textes ne sont jamais enregistrés, jamais copiés et jamais envoyés, ni à nous, ni au parent, ni à personne. Cocorico fonctionne sans intelligence artificielle et sans serveur.

3. Ce qui part sur Internet

Des alertes courtes envoyées au parent par le service gratuit ntfy (ntfy.sh), sur un canal secret créé au hasard. Ces alertes disent par exemple :

  • « 3 codes parent faux ont été saisis » ;
  • « Cocorico est désactivé » / « Cocorico réactivé » ;
  • « Quelqu'un a ouvert un réglage protégé » ;
  • « Votre enfant demande de l'aide », si l'enfant touche le bouton « J'ai besoin d'aide » ;
  • un message quotidien « Cocorico actif » (désactivable) ;
  • le type d'un message masqué, l'application et l'heure (par exemple « Message à caractère sexuel masqué sur Snapchat à 21:40 »), tout de suite pour les messages graves, et dans un bilan du soir pour tous (désactivable).

Les alertes ne contiennent jamais le texte des messages de l'enfant, ni l'expéditeur, ni ses contacts, ni sa position, ni ses photos.

Le service ntfy reçoit ces alertes pour les transmettre ; il a sa propre politique de confidentialité (ntfy.sh).

Cocorico télécharge aussi, une fois par jour, la liste de mots à jour depuis GitHub (github.com). Rien n'est envoyé : comme pour toute page web, GitHub voit seulement l'adresse IP du téléphone. Chaque liste est signée : Cocorico refuse une liste qui ne vient pas de nous.

4. Ce qui reste sur le téléphone

Les réglages de Cocorico : le niveau de protection, les applications choisies, les mots ajoutés par le parent, le canal d'alerte, et une empreinte du code parent et du code de secours (les codes eux-mêmes ne sont jamais enregistrés en clair). Ces données ne quittent pas le téléphone et sont effacées en désinstallant Cocorico.

5. Autorisations utilisées

  • Service d'accessibilité : lire et masquer les textes, protéger les réglages (voir points 1 et 2).
  • Administrateur de l'appareil (si le parent l'active) : uniquement pour empêcher la désinstallation sans le code parent. Cocorico n'utilise aucun autre pouvoir (ni effacement, ni verrouillage, ni caméra).
  • Internet : uniquement pour les alertes et le téléchargement de la liste de mots (point 3).
  • Notifications : afficher en permanence « Cocorico protège ce téléphone », pour que l'enfant sache que l'application est active.
  • Démarrage du téléphone : relancer la vérification régulière après un redémarrage.

6. Pas de publicité, pas de vente de données

Cocorico ne contient ni publicité, ni traceur, ni outil de statistiques. Aucune donnée n'est vendue ni partagée.

7. Enfants

Cocorico s'adresse aux parents. Il est conçu pour protéger les enfants et les adolescents sans lire leurs conversations à leur place : le parent ne voit un message masqué qu'en saisissant son code sur le téléphone de l'enfant. Une notification permanente informe l'enfant que Cocorico est actif.

8. Vos droits

Comme Cocorico ne collecte aucune donnée personnelle sur un serveur, il n'y a rien à consulter ni à supprimer chez nous. Pour tout effacer : désinstallez Cocorico (bouton « Retirer la protection » dans les réglages parent, puis désinstallation).
