COCORICO

Questions fréquentes

Les réponses aux questions que se posent les parents. Touchez une question pour lire la réponse.

Combien coûte Cocorico ?

Cocorico est gratuit à télécharger, puis fonctionne par abonnement, par téléphone protégé : 2,99 € par mois ou 29,99 € par an. Le premier mois est offert, pour tester et vous habituer à l'application. L'abonnement se prend dans Cocorico (réglages parent), il est payé et géré par Google Play, et il est résiliable à tout moment depuis Google Play, rubrique « Paiements et abonnements ».

Sur quels appareils Cocorico fonctionne-t-il ?

Sur les smartphones et tablettes Android (Samsung, Xiaomi, Google Pixel, Oppo, Motorola…), à partir d'Android 8. Cocorico s'installe sur l'appareil de l'enfant. Il ne fonctionne pas sur iPhone, iPad ni ordinateur : Apple ne permet pas ce type de protection.

Que se passe-t-il si l'abonnement s'arrête ?

Vous êtes toujours prévenu avant, par une alerte sur votre téléphone : fin de l'essai gratuit, résiliation, ou paiement refusé. En cas de problème de paiement, la protection continue encore 3 jours, avec un rappel chaque jour. Si l'abonnement n'est pas repris, les messages ne sont plus masqués et vous recevez une dernière alerte. La protection ne s'arrête jamais sans que vous le sachiez.

Cocorico lit-il les conversations de mon enfant ?

Cocorico lit les textes affichés à l'écran, uniquement dans les applis que vous avez cochées, pour masquer ceux qui sont blessants. Tout se passe sur le téléphone : rien n'est enregistré, rien n'est envoyé, il n'y a ni serveur ni intelligence artificielle. Vous-même ne lisez un message masqué qu'avec votre code.

Quelles applis sont protégées ?

SMS, WhatsApp, Instagram, TikTok, Snapchat, Facebook, Messenger, YouTube, Discord, Telegram, Signal, X, Threads, Reddit, Twitch, Yubo, BeReal, ainsi que les aperçus de notifications. Vous choisissez lesquelles dans « Applications protégées ».

Les discussions à l'intérieur des jeux (Roblox, Fortnite, Minecraft) ne peuvent pas être lues par Android : Cocorico ne peut pas les masquer.

Que masque Cocorico exactement ?

Les insultes, menaces, incitations au suicide, propos racistes, sexistes, homophobes, moqueries du physique, demandes de photos intimes et, si vous le choisissez, les gros mots.

Il reconnaît les fautes d'orthographe, les abréviations (fdp, ntm…), le verlan, les insultes en anglais, les emojis utilisés comme insultes (« t'es un 🐷 », 🖕) et les déguisements (c0nn4rd, c.o.n, lettres espacées). Choisissez le niveau dans « Niveau de protection ».

Une insulte passe, ou un message normal est masqué : que faire ?

Ajoutez le mot dans « Mots à masquer », ou essayez la phrase dans « Essayer une phrase ». Si un message normal est masqué à tort, baissez le niveau de protection. L'argot change vite : la liste est enrichie à chaque nouvelle version.

Comment lire un message masqué ?

Sur le téléphone de l'enfant, faites un appui long sur le message masqué : Cocorico demande le code parent, puis affiche le message quelques secondes. Il n'est jamais enregistré.

Mon enfant peut-il désactiver ou désinstaller Cocorico ?

C'est rendu difficile : les réglages du téléphone qui permettent de couper Cocorico demandent le code parent, la désinstallation est bloquée (si vous avez touché « Bloquer la désinstallation »), et vous êtes prévenu si la protection est coupée.

Seule limite : le « mode sans échec » d'Android coupe Cocorico. Vous le remarquerez, car le message quotidien « Cocorico actif » n'arrivera plus.

Comment recevoir les alertes sur mon téléphone ?

Installez l'appli gratuite « ntfy » sur votre téléphone (Android ou iPhone), touchez « + » et abonnez-vous au canal affiché dans « Code parent et alertes ». Plusieurs parents peuvent s'abonner au même canal. Touchez « Envoyer une alerte de test » pour vérifier.

Que contiennent les alertes ?

Le type de message masqué (menace, message sexuel, insulte…), l'appli et l'heure. Jamais le texte du message ni l'expéditeur.

Les messages graves arrivent tout de suite, les autres dans le bilan du soir (après 20 h). Vous êtes aussi prévenu des codes faux et si la protection est coupée.

Mon enfant sait-il qu'il est protégé ?

Oui : une notification permanente « Cocorico protège ce téléphone » reste affichée. C'est une obligation de Google, et c'est aussi plus honnête. Nous conseillons d'en parler avec lui : Cocorico protège, il ne surveille pas.

J'ai oublié mon code parent.

Sur l'Espace parent, touchez « Code oublié ? » et saisissez le code de secours qui vous a été donné à la création de votre code parent : vous choisirez un nouveau code (et recevrez un nouveau code de secours). Vous pouvez en créer un dans « Code parent et alertes » si vous n'en avez pas.

Sans code de secours, il faut redémarrer le téléphone en mode sans échec, retirer Cocorico des « applis d'administration de l'appareil », puis le désinstaller et le réinstaller.

Cocorico vide-t-il la batterie ?

Non : il ne travaille que lorsque l'une des applis protégées est à l'écran. Il consomme en général environ 1 % de la batterie par jour.

Un message masqué peut-il apparaître un instant ?

Quand on fait défiler très vite, un nouveau message blessant peut être visible une fraction de seconde, le temps que Cocorico relise l'écran. Les messages déjà masqués restent couverts pendant le défilement.

Mon enfant peut-il demander de l'aide ?

Oui : dans la notification « Cocorico protège ce téléphone », et sur l'Espace parent, le bouton « 🆘 J'ai besoin d'aide » ouvre un écran sans code. Il peut vous prévenir d'un appui (vous recevez « Votre enfant demande de l'aide » dans ntfy, sans aucun message ni nom), appeler le 3018 ou le 17.

Mon enfant est harcelé : que faire ?

Parlez-en avec lui sans le culpabiliser, gardez des preuves (captures d'écran avec la date), ne répondez pas au harceleur, et appelez le 3018 : numéro national gratuit et anonyme contre le harcèlement en ligne (7j/7, aussi par appli et tchat sur 3018.fr). Il aide aussi à faire supprimer des contenus.

En cas de danger immédiat : 17.
